# Planning v4 如何规划（纵 / 横 / 变道 / 视野 / 拥堵 / 避险）

> 配套 [planning_lon_v4.md](./planning_lon_v4.md) 的**做法说明书**。不是量产法规，是正常人逻辑 + 可冒烟。  
> 表里「第一刀」= 结构必须先有；「后挂」= 输入或搜索来了接到同一份计划上。  
> **金源只改 `.m`**，Host 认完再 generate C。每拍 `O(traj_n × obj_n_max)`，禁止重搜索占时间片。Host 时钟/BEV/相机旁路见 [host_fps_sil_hil.md](./host_fps_sil_hil.md)（先稳 ≥20 Hz 再改标定）。

## A. 每一拍在算什么

不要先分类 ACC/AEB。固定顺序：

```text
1. 视野   → D_see, T_plan, v_cap_vis     （能看多远、这段里最高开多快）
2. 场景   → 车道拓扑、目标、遮挡、质量     （开放集合，见 §C）
3. 走廊   → 候选路径（先本车道；后挂左/右变道）
4. 速度段 → 沿走廊按约束削出分段 v / a   （空了抬、挡了压、看不见当有风险）
5. 选计划 → 代价：进展 vs 碰 vs 视野 vs 舒适 vs 变道必要性
6. 执行   → 跟计划此刻的 v、路径；近处 a_req 再削一刀
```

输出必须能画：**路径折线 + 分段速度 + 本拍 T_plan**。BEV 上看得出未来加减和会不会换道，才叫有计划。

代价直觉（类 A*，数进 cal）：

- 进展：越接近巡航、越少无谓停车越好  
- 碰撞：沿走廊与他车时距不够则重罚（看不见的区域当「可能有东西」罚，不当空路奖）  
- 视野：计划不得画过 `D_see` 还当畅通  
- 舒适：猛加猛减、猛打方向加代价  
- 变道：没必要不换；该换（车道没了、前车长期堵死且邻道真空）才换

## B. 视野：好怎么开、不好怎么避

这是计划的尺子。尺子短了，整份计划都要改性格，不是只把轨迹画短一点。

### B.1 怎么得到尺子

```text
D_fov_conf   ← FOV × 清晰度/置信 标定距离
D_vr         ← 车道线可视（VR_End、线质量）
D_occlusion  ← 前方大车/弯道挡视线：挡后打折或截断
D_see        ← min(以上, D_cal_cap)
T_plan       ← min(T_base≈10s, D_see / max(v, v_floor))
v_cap_vis    ← 在 D_see 内仍能从容收住的车速上限（标定，不是法规 AEB）
```

`T_base` 是「视野好时我想看到约 10 s」。从好变坏、从坏变好：`T_plan` / `v_cap_vis` **带滞回**，避免隧道口闪一下就抽一下油门。

### B.2 视野好

人会：看远、走得顺、早做决定，而不是踩死。

- `T_plan ≈ T_base`，BEV 上接近 10 s 的路 + 分段速度。  
- 巡航意愿可以到 `cruise_v`，但仍 ≤ `v_cap_vis`（好天气通常够用）。  
- **早让、早抬：** 远处插入、车道变少、邻道真空，写在后面几段速度上，不要等贴脸。  
- **允许考虑变道走廊**（搜索可以后挂，合同允许）：因为看得见目标车道和空档。  
- 邻道更慢、没往里趋势：通过，剖面上留刹车余量，不先把自己刹成一样慢。  
- 空了：后面几段逐步抬速，不是本拍油门地板一脚踩满。

### B.3 视野不好（雾、夜、线糊、大车挡、隧道口致盲、VR 短）

人会：看不清就慢、不换道、不把挡后面当空的、脚搁在刹车上。

| 做 | 不做 |
|----|------|
| 缩短 `T_plan`，计划只画到信得过的地方 | 仍按 10 s 当远方畅通去抬速 |
| 全段 `v ≤ v_cap_vis`（尺子短则上限低） | 巡航 12 m/s 冲进看不清的里 |
| 加时距：同样 closing，速度段更早开始降 | 等 `d < d_stop` 再进 AEB 档 |
| 大车后：`D_occlusion` 截断，挡后当未知占位 | 从车缝里当空路加油 |
| **禁止变道搜索**（看不见目标车道/后车） | 糊线还往邻道甩 |
| 执行侧 `a_req` 更敏感（准备刹车写在计划里） | 标签切到 AEB 才算刹车 |
| 线没了 / `e_y` 离谱：计划速度收到接近 0 | 视野差还用巡航地板往前拱 |

进出隧道：按「视野突然变差/变好」处理——进：先降 `D_see` 和 `v_cap_vis`；出：滞回后再拉长计划，避免出光瞬间当高速公路。

### B.4 冒烟（视野）

| 冒烟 | 期望计划 | 禁止 |
|------|----------|------|
| 直道、线好、无遮挡 | ~10 s 路，后段可到巡航 | 无故全刹 |
| 前有大货车 | 计划收到车尾+余量，速度段提前降 | 货车后当空路 pullaway |
| 线质量差 / VR 20 m | 短计划、低 `v_cap_vis` | 长走廊画到 100 m |
| 隧道口 | 短、慢、不变道 | 仍 10 s 抬速 |
| 出隧道视野恢复 | 滞回后才拉长、抬速 | 立刻 0.78 油门 |
| 大车换道露出空档 | 确认 `D_see` 变长后再抬后段速度 | 刚露缝就地板油 |

## C. 场景往计划上挂（开放，不是清单做完才叫 v4）

同一份计划，证据只改走廊或速度段。

| 证据 | 第一刀 | 后挂 |
|------|--------|------|
| 本车道前车 d/rel | ✓ | |
| 邻道车 lat + rel（通过 vs 可能插入） | ✓ 锥作权重 | 横向速度、灯 |
| 多目标不只 CIPV | 能列则列 | 必选 |
| 车道线 / VR / e_y | ✓ | |
| 前方大车遮挡 | 有 bbox 即可估 | 精细轮廓 |
| FOV/清晰度 → `D_fov_conf` | cal 占位 | 感知质量真值 |
| 转向灯、航向变化 | | ✓ |
| 车道数增减、汇入锥 | | 地图/LA 拓扑 |
| 进出隧道、出光 | | 场景或地图 |
| 环视后车加速/变道 | | 环视 |
| 行人、非机动车 | 若 DYN 有则当目标 | |
| 路沿/墙 | 纵向往往没有 | 横向上靠留在车道；不要指望 DYN AEB 墙 |

## D. 纵向：分段速度怎么削

沿**已选走廊**从近到远扫约束，削出若干段 `(s0,s1, v, a)`。不是跟车状态机。

**意愿：** 视野允许下的巡航（`min(cruise_v, v_cap_vis)`）。空、约束松 → 后段抬向意愿。  
**约束：** 每个相关目标给出「到那一段时希望的 v / 所需减速度」。取严。closing 大、d 小 → 该段 a 更负。看不见的前方（遮挡、VR 外）当未知，**降速或不延伸计划**，不奖励「当空」。

典型段（名称仅便于看 BEV，不是模式）：

- **抬：** 空了、前车加速或打出本车道灯、时距够  
- **巡：** 接近意愿、约束松  
- **收：** 前车靠近、插入预判、汇入、视野变差  
- **预备刹：** 后段已经是明显负 a，执行脚可以搁着，不是等档位  
- **饱和：** 极近仍在走廊上，该段 a → `a_max`（日志可标 aeb）

跟停：近处段 v→0；空了且 `D_see` 够，后段再抬。没有独立 pullaway 控制器。  
超邻道慢车：本车道走廊、速度段不必跟它对齐。  
拥堵：意愿临时降到车流，段与段之间小、早收早抬，禁止为抢 2 m 把后段顶满。

### 纵向冒烟

| 冒烟 | 期望 |
|------|------|
| 空直道视野好 | 后段到巡航，平滑抬 |
| 静止前车 40 m，v 高 | 远段就收，近段更收；贴脸前已是重刹段，不是 20 m 才 saturates 0.55 |
| 前车突然打灯进我车道 | 插入段提前降 v |
| 前车打灯离开 | 确认空档后后段抬 |
| 邻道平行更慢 | 通过，不无故跟停 |
| 停住贴前车 | 近段 v=0；间隙不够不抬 |
| 间隙够且视野好 | 后段抬，油门跟剖面不是 0.78 一脚 |
| 车速超过意愿 | 段内收，执行只刹不加油 |
| 拥堵 stop-go | 短段、早收；不变道除非走廊明显更好 |

## E. 横向：走廊 vs 这一拍转向

计划路径是横向的**未来**；LKA/限舵速是**走这条路**。

- 选本车道：路径沿中心（blend），执行跟 `e_y`、限 `dsteer`。  
- 选变道：路径先沿本车道再偏入邻道，执行跟这条斜线，不是先打死方向再想速度。  
- `|e_y|` 大或线不可用：路径不可信 → 速度段降到接近 0，转向收向 0（限速），**不要**无轨迹还巡航。  
- 视野差：即使线还在，也不开变道走廊。  
- 路沿/墙不在 DYN：避事故首先是**人在车道里**；计划不要把人画到线外。

### 横向冒烟

| 冒烟 | 期望 | 禁止 |
|------|------|------|
| 微偏 e_y | 路径居中，舵缓 | 抽一下满舵 |
| e_y=28 / 线飞了 | 短计划、v≈0、舵回 0 | 巡航地板 + 最大舵 |
| 切车在右 | 路径仍本车道（或后挂：让速不让路） | 往左墙躲把人开出车道 |
| 变道计划中 | 路径能看出换道 | 只有速度变、路还画在原车道中心 |

## F. 变道（计划上的走廊，不是本拍抽一下）

正常人：看得到、有空档、有必要才换；换的过程中随时可放弃。

**可以出现在计划上（后挂搜索，合同不锁死永不换道）：** 本车道长期堵死且邻道真空且 `T_plan` 够长；车道即将没了/汇入；前车故障趴窝且邻道安全。

**不要换：** 视野差；目标车道有车在关窗；后车（环视）正在加速占该空档；只为快 1 m；正在被旁车插入。

换道计划：走廊几何 + 该走廊上的速度段（往往先收或稳住，再在空档里走）。执行跟走廊。空档消失 → **改回本车道走廊**（abort），不要硬切完。

第一刀可以只有「本车道」一个走廊，但输出结构要留得多走廊，否则以后 A* 换道会推翻纵向。

### 变道冒烟

| 冒烟 | 期望 |
|------|------|
| 邻道空、前车 10 km/h 长期堵、视野好 | 计划可出现换道走廊 + 分段速度 |
| 同上但大雾 | 不换，只在本车道降速 |
| 换到一半邻道来车 | abort 回本车道，速度段收 |
| 后车环视在加速 | 不抢同一空档 |

## G. 交通繁忙

车流密：计划变短、变怂、变窄——仍是计划，不是改成分档蠕行器。

- `T_plan` 常被前车/遮挡削短，这是正常的。  
- 速度段贴近前车时距，意愿不再是空道巡航。  
- 多车可能插入：`a_req` 取严，后段早收。  
- 拉链汇入：预留空档（后挂拓扑）；第一刀至少「锥形路提前降速」。  
- 禁止：为穿空档把 `v_cap_vis` 顶满；密车流里变道来回切。

### 拥堵冒烟

| 冒烟 | 期望 |
|------|------|
| 车队 8 m 间距 | 段速度跟车流，不冲巡航 |
| 左右都有车平行 | 本车道通过或跟，不变道 |
| 前车点刹 | 近段跟着收，不是等 TTC 档 |
| 夹缝 cut-in | 让插入（压速），不加速去顶 |

## H. 避免事故（不是 AEB 状态）

分层，都作用在计划或执行上：

1. **别开出车道**（墙、沟、护栏常常不在 DYN）。  
2. **别把看不见当空**（遮挡、VR 外、致盲）。  
3. **早改速度段**（插入、汇入、前车减速）——避事故的主手段是计划，不是最后一脚。  
4. **近处饱和**（走廊上极近、closing 大）——全力减，标签可叫 aeb，无 latch。  
5. **后车（环视后）：** 自己不无故猛刹；若必须重刹，计划允许的话略让走廊，而不是刹车点给后车。  
6. **执行 `a_req`：** 计划若偏乐观，本拍相对运动再削一刀（双保险，仍不是第二套状态机）。

CCRU / 横穿：目标在走廊或将进入走廊，速度段按相对运动收；邻道远、无进入趋势，不按墙打。  
行人：有就当高权重目标。  
自车已经在走廊外（e_y 炸）：先停住横向乱飞，不要为躲 DYN 再往墙上打。

### 避险冒烟

| 冒烟 | 期望 | 禁止 |
|------|------|------|
| 静止物体在本车道，视野好 | 远段就收到 0，近段饱和 | 17 m/s 到 20 m 才 0.55 |
| 邻道平行物体 | 通过或轻收，不饱和 | 当墙 AEB |
| 物体从邻道往里 | 插入段提前收 | 进锥才切档 |
| CIPV 跳到 lat=11 | 原威胁若还在走廊要继续按其约束；跳走不当空路猛加油 | 立刻 cruise 地板 |
| 撞前 e_y 飞掉 | v→0，舵不乱 | 无轨迹还加速 |
| 后车近（有环视） | 能不猛刹则靠早收；必须刹则刹 | 无计划点刹 |

## I. 执行（计划之后）

`throttle, brake` 跟踪 `v_plan(0)`；`steer` 跟踪路径。`a_req` 优先。视野差时 `v_plan` 已被 `v_cap_vis` 压过，执行不要再偷偷拉巡航地板。

标签（cruise / acc / aeb）只描述本拍力度，不进下一拍。

## J. 落地刀（仍按这个性格切，不要切回分档）

| 刀 | 有什么 |
|----|--------|
| **1 计划对象** | `T_plan`（T_base+VR）、路径点 + 每点或每段 v；执行跟剖面；去掉互斥档 |
| **2 视野尺子** | `D_see` = min(FOV×conf, VR, 遮挡, cap)；坏变好滞回；`v_cap_vis`；`allow_lc` 仅视野够时 |
| **3 多目标权重** | ≤`obj_n_max` 个目标取严；邻道通过 vs 朝里插入连续权重；行人抬权 |
| **4 走廊搜索** | 现只本车道 + `allow_lc` 旗标；第二走廊等认完刀 2/3 再加，且不得变成每拍网格搜 |
| **5 场景后挂** | 灯、隧道标志、环视后车：钩在 `D_see` / 权重；无输入则 conf/VR/遮挡先顶上 |

**BEV（已开始画计划）：** 路径按 `points_v_mps` 着色（红慢/绿巡航），青色虚线是 `D_see`，顶栏 `V`/`D`/`T`。不是本拍 cruise/acc/aeb 名字。变道走廊以后挂。

**CARLA 场景（后续重做，本文是支撑）：** 造场景尽量满足 how 里的冒烟，并故意超出（更差视野、更密车流、挡视线、汇入、后车）用来打计划，而不是只验证旧 ACC/AEB 档。

金向量按 §B.4 / D / E / F / G / H 的冒烟锁「计划形状 + 禁止项」，不锁模式名。
