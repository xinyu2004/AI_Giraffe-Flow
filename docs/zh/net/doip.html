DoIP

把诊断仪和 ECU 之间的诊断报文从 CAN 搬到以太网。连上之后，载荷里跑的是 UDS。

一次诊断怎么连上

ISO 13400。诊断仪先在网上找到车，再建 TCP，做路由激活，然后才能把 UDS 送进去。顺序不能倒。

步骤走哪结果
找车UDP 13400车用 0x0004 回答 VIN、EID、GID 和自己的逻辑地址。车辆宣告也是这一条，由车主动送出
建连TCP 13400，套 TLS 时是 TCP 3496字节流立起来。刚连上若一直不做激活，规范里的初始无活动定时器会把连接拆掉，默认大约 2 秒
路由激活TCP，0x0005 / 0x0006诊断仪的源地址在这台 DoIP 实体上登记。成功码是 0x10
诊断报文TCP，0x8001里面才是 UDS。DoIP 先回 0x8002 或 0x8003，表示收不收这包，不是 UDS 的正响应
保住连接TCP激活之后大约 5 分钟没有报文，一般无活动定时器会拆连接。诊断仪用 UDS 的 TesterPresent 续上

同一个源地址已经在另一条 TCP 上，实体会先做存活检查（0x0007 / 0x0008）。旧连接还活着，新的激活会被拒绝。

路由激活的结果

请求里带诊断仪的源地址和激活类型。默认类型是 0x00。法规诊断用的 WWH-OBD 是 0x01。响应码里常用的有：

码含义
0x10激活成功
0x11要再确认一次，随后才算成功
0x00不认识这个源地址
0x01TCP 套接字已经满了
0x02这条连接上已经有别的源地址
0x03这个源地址正在另一条连接上
0x04还缺认证
0x06不支持这种激活类型
0x07拒绝明文，要求改走 TLS

见到 0x07，就关掉 13400 上的明文 TCP，改连 3496，做完 TLS 握手再发一次路由激活。DoIP 的头在 TLS 记录里面。

在哪一层

应用层。诊断报文固定走 TCP。这条已经是可靠字节流，总图上 TLS 一开始就能勾。找车和宣告走 UDP 13400。总图上 SecOC 和 E2E 不套在 DoIP 上。

报文

头是四段：协议版本、版本的反码、载荷类型、载荷长度。反码是版本字节按位取反，用来尽早认出这不是一条 DoIP。

版本1 字节
反码1 字节
类型2 字节
长度4 字节
载荷由类型决定
类型名字方向
0x0000头本身不合法时的否定实体 → 诊断仪
0x0001车辆识别请求UDP
0x0002 / 0x0003按 EID 或按 VIN 找UDP
0x0004车辆宣告，也是识别响应。带 VIN、EID、GID、逻辑地址UDP
0x0005 / 0x0006路由激活请求和响应TCP
0x0007 / 0x0008存活检查TCP
0x4001 / 0x4002实体状态：还能接几条连接、已经接了几条UDP
0x4003 / 0x4004诊断电源模式UDP
0x8001诊断报文，载荷是 UDSTCP，双向
0x8002 / 0x8003诊断报文的肯定 / 否定确认实体 → 诊断仪

0x8001 和它的确认

诊断报文的载荷是源地址、目的地址，然后才是 UDS。源地址是诊断仪，目的地址是一个 ECU，或一个功能地址（一组 ECU 都听）。具体编号由厂商分配，外部测试设备常用的那一段在规范里单独留出。

源地址2 字节
目的地址2 字节
UDSISO 14229

0x8002 只说明 DoIP 实体收下了这包、可以往下送。UDS 的正响应是稍后另一条 0x8001，服务号是请求号加 0x40。0x8003 是否掉这包，常见原因：

码含义
0x02源地址无效
0x03不认识目的地址
0x04诊断报文太大
0x05内存不够
0x06目的到不了
0x07不认识要走的网络
0x08下层传输出错

载荷里常见的 UDS

UDS 的服务怎么编码仍看 ISO 14229，这里只列诊断仪最常放进 0x8001 的那些。否定响应是 0x7F，后面跟原服务号和否定码。

服务号用来做什么
DiagnosticSessionControl0x10进入默认、扩展或编程会话
ECUReset0x11复位
ClearDiagnosticInformation0x14清故障码
ReadDTCInformation0x19读故障码
ReadDataByIdentifier0x22按数据标识读
SecurityAccess0x27解锁。种子和密钥的算法不在这页
WriteDataByIdentifier0x2E按数据标识写
RoutineControl0x31启动、停止或问一个例程
RequestDownload / TransferData / RequestTransferExit0x34 / 0x36 / 0x37刷写时的下载三步
TesterPresent0x3E保住当前会话，也帮 DoIP 的无活动定时器续命

不做什么

  • 不规定 UDS 每个服务的参数布局。那是 ISO 14229。
  • 0x8002 不是 UDS 正响应。正响应仍是一条 0x8001。
  • 地址是 DoIP 的逻辑地址，不是 CAN 标识符。
  • 总图上 SecOC 和 E2E 不套在 DoIP 上。这条 TCP 要保护，用 TLS 或 IPsec。
