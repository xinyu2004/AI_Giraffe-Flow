OSI seven layers

Top to bottom: application, presentation, session, transport, network, data link, physical. The application example is SOME/IP, transport is UDP, and network is IPv4. Presentation and session add no header or trailer. In 1982 Ethernet II the data link writes the destination MAC, source MAC, and EtherType, and adds the FCS at the end of the frame. In 1998, 802.1Q inserts 4 bytes between the source MAC and the EtherType.
